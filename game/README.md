# ⚽ ITOSHI RIN // FLOW DESTRUCTION SHOT (Raylib C++ 2D)

Повноцінна 2D-мінігра на C++17 з використанням бібліотеки **Raylib** у фірмовій естетиці Ітоші Ріна з аніме/манги *Blue Lock*.

---

## 🎮 Механіки геймплею
1. **Прицілювання та удар (Slingshot):**
   - Затисніть ЛКМ на м'ячі та відтягніть мишку назад для налаштування сили й вектора польоту.
   - Відпустіть ЛКМ, щоб виконати удар.
2. **Регулювання підкрутки (Curve / Spin Control):**
   - Клавіші `A` або `Q` — закрутити м'яч ліворуч.
   - Клавіші `D` або `E` — закрутити м'яч праворуч.
   - Індикатор на HUD відображає точне значення кутової швидкості обертання (RPM).
3. **Фізика польоту (Ефект Магнуса):**
   - Реалістична бічна сила прискорення перпендикулярно вектору руху за формулою ефекту Магнуса: \( \vec{a} = k \cdot \omega \times \vec{v} \).
   - Аеродинамічний опір повітря (поступове сповільнення).
   - Відскоки від штанг та поперечини з розрахунком нормалі.
4. **Воротар та стінка захисників:**
   - Воротар з реактивним штучним інтелектом розраховує траєкторію перетину лінії воріт і здійснює сейви.
   - Рухомі силуети захисників блокують прямі удари, змушуючи гравця закручувати м'яч по дузі.
5. **Стан FLOW (Пробудження руйнівника):**
   - Успішні голи з сильною підкруткою заряджають шкалу Flow.
   - При 100% заряду натисніть `ПРОБІЛ` або `F` — активується режим абсолютного знищення:
     * Бірюзово-полум'яний шлейф розпаду за м'ячем.
     * Множник сили підкрутки ×2.5.
     * Нові фірмові репліки Ріна в діалоговому HUD.

## 🛠️ Як зібрати проєкт

### Варіант 1: Через CMake
```bash
mkdir build
cd build
cmake ..
cmake --build .
```

### Варіант 2: Через g++ / MinGW
```bash
g++ -std=c++17 main.cpp game.cpp -o ItoshiRinGame.exe -lraylib -lopengl32 -lgdi32 -lwinmm
./ItoshiRinGame.exe
```

### Варіант 3: Онлайн / Веб
Гра також інтегрована у вигляді HTML5 Canvas симулятора прямо на фан-сайті у розділі «Міні-гра»!
